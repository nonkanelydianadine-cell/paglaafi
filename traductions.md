## 🔴 5. Étapes de l'auto-examen — Descriptions

> Textes d'instruction qui guident l'utilisatrice geste par geste. Indispensables pour faire l'examen correctement.

| # | Français | Mooré | Dioula | Fulfuldé |
|---|----------|-------|--------|----------|
| Étape 1 | Choisissez un moment calme, idéalement quelques jours après vos règles. Déshabilllez-vous jusqu'à la ceinture et placez-vous dans un endroit bien éclairé. | | | |
| Étape 2 | Placez-vous debout face à un miroir, bras le long du corps. Observez attentivement vos seins : leur forme, leur taille, la couleur de la peau, et si les deux seins sont symétriques. | | | |
| Étape 3 | Levez les deux bras au-dessus de la tête. Observez si vos seins se soulèvent de manière symétrique, si la peau change d'aspect, si vous voyez des fossettes ou des zones de rétraction. | | | |
| Étape 4 | Avec votre main droite, palpez doucement l'aisselle gauche en effectuant de petits cercles. Recherchez des ganglions ou des bosses inhabituelles. Répétez avec l'autre côté. | | | |
| Étape 5 | Avec les doigts de la main droite à plat, palpez doucement le sein gauche en faisant de petits cercles. Partez du mamelon et remontez vers la clavicule, puis vers l'aisselle. Couvrez toute la surface. | | | |
| Étape 6 | Répétez la même palpation sur le sein droit, cette fois avec les doigts de la main gauche. Effectuez les mêmes petits cercles en couvrant toute la surface du sein droit. | | | |
| Étape 7 | Allongez-vous sur le dos. Placez un oreiller sous l'épaule droite et palpez le sein droit avec la main gauche. Puis placez l'oreiller sous l'épaule gauche et palpez le sein gauche avec la main droite. | | | |

## 🟡 7. Contenu informatif — Textes des articles

> Corps des articles affichés dans l'écran "Informations". Ces textes expliquent le cancer, les signes et la prévention.

| Article | Français | Mooré | Dioula | Fulfuldé |
|---------|----------|-------|--------|----------|
| Cancer — C'est quoi ? | Le cancer du sein est une maladie où des cellules anormales se développent dans le sein. Il peut toucher toute femme à tout âge, mais est plus fréquent après 40 ans. Détecté tôt, il se soigne mieux. | | | |
| Cancer — Dépistage | Détecté tôt, le cancer du sein se soigne beaucoup mieux. Le taux de guérison dépasse 90% quand il est pris en charge à un stade précoce. L'auto-examen mensuel peut sauver des vies. | | | |
| Signes précoces | Surveillez ces signes : une boule ou épaississement dans le sein ou l'aisselle, un changement de forme ou de taille du sein, un écoulement du mamelon, une rougeur ou peau d'orange, une douleur persistante. | | | |
| Quand consulter ? | Consultez un médecin sans attendre si vous remarquez l'un des signes ci-dessus, si votre auto-évaluation indique un risque modéré ou élevé, ou si vous avez des antécédents familiaux de cancer du sein. | | | |
| Prévention quotidienne | Adoptez ces habitudes protectrices : pratiquez une activité physique régulière, maintenez un poids santé, allaitez vos enfants si possible, limitez la consommation d'alcool, évitez le tabac et effectuez un auto-examen mammaire chaque mois. | | | |
| Auto-examen mensuel | L'auto-examen mammaire est un geste simple que toute femme peut apprendre. Il consiste à palper ses seins une fois par mois, idéalement quelques jours après les règles, pour détecter toute anomalie. Utilisez le guide disponible dans l'application. | | | |
| Facteurs de risque | Certains facteurs augmentent le risque de cancer du sein : des antécédents familiaux (mère, sœur, fille atteinte), l'âge supérieur à 40 ans, une première grossesse après 35 ans, l'absence d'allaitement, la sédentarité, la consommation d'alcool et le tabac. | | | |
| Signification des risques | Avoir des facteurs de risque ne signifie pas que vous aurez forcément un cancer du sein. Cela signifie simplement que vous devez être plus vigilante, pratiquer l'auto-examen chaque mois et consulter un médecin régulièrement pour un suivi. | | | |
